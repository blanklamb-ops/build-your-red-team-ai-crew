USAGE
================================================================================

1. Install dependencies:
   $ npm install

2. Run all tests:
   $ npm test

3. Load extension:
   - Open chrome://extensions/
   - Enable Developer mode
   - Load unpacked: select workspace/extension/

4. Record auth flow:
   - Click extension icon
   - Click "Enable Lab Access"
   - Reload extension if prompted
   - Click "Start Recording"
   - Browse authorized lab flow
   - Click "Stop Recording"
   - Click "Export JSON"

5. Generate phishlet:
   $ node generators/cli.js generate <capture.json>
