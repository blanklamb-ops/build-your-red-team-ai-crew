================================================================================
INTEGRATION APPROACH
================================================================================

Decision: Sidecar model (not GoPhish fork)

Workflow:
1. Operator exports campaign JSON from GoPhish
2. Run gophish-ics generate to create .ics file
3. Attach ICS to GoPhish email template manually
4. Campaign executes via GoPhish
5. Simulate RSVP responses (lab) or integrate webhook (production)
6. Generate RSVP report

Rationale: Minimizes maintenance burden, clean separation, simpler deployment
